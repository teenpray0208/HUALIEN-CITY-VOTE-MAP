# 花蓮市各里投票分布地圖

參照「屏東縣 2026 選情預估地圖」的資訊架構製作，以 Leaflet 顯示花蓮市政府公開圖層目前回傳的 44 個里界。

## 使用方式

在此資料夾啟動靜態伺服器：

```powershell
python -m http.server 4173
```

瀏覽 `http://localhost:4173/`。

## 資料說明

- 花蓮市總票數：2024 第 16 任總統副總統選舉中選會公布結果。
- 村里界：花蓮縣政府公開 ArcGIS 圖層（村里界圖層 ID 11）。
- 各里票數：目前為依花蓮市總票比例建立的互動展示資料，介面已清楚標示，不應作為正式統計引用。之後可將 `allocateVotes()` 替換為中選會各投開票所彙整後的正式里級票數。

## 特色

- 點擊里界查看候選人票數與比例
- 「候選人勝出／勝出幅度」兩種著色模式
- 里名搜尋與地圖定位
- 花蓮市總票數、各候選人領先里數、排名卡
- 響應式手機版面
